# 🌐 Curso de Fundamentos de HTML5

Todo el código, prácticas y ejercicios organizados paso a paso que desarrollé durante el curso de **Fundamentos de HTML**.

---

## 📁 Estructura del Repositorio

El contenido está dividido por módulos o clases, abarcando desde lo más elemental hasta conceptos avanzados de accesibilidad y SEO:

| Carpeta | Contenido / Temática |
| :--- | :--- |
| 📄 `clase_01_estructura_base` | Estructura principal de un documento HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`). |
| 🏷️ `clase_02_titulos_sub` | Encabezados (`<h1>` - `<h6>`), párrafos y jerarquía de texto. |
| 🖼️ `clase_03_imagenes` | Inserción de imágenes (`<img>`), atributos `src`, `alt`, rutas relativas y absolutas. |
| 📋 `clase_06_listas` | Listas ordenadas (`<ol>`), desordenadas (`<ul>`) y de definición (`<dl>`). |
| 🏗️ `clase_07_estructura_semantica` | Etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`). |
| 📝 `clase_08_Formularios` | Creación de formularios nativos (`<form>`, `<label>`, `<button>`). |
| 📥 `clase_09_tipos_inputs` | Tipos de entradas (`text`, `password`, `email`, `number`, `checkbox`, `radio`, etc.). |
| ✅ `clase_10_validaciones` | Validaciones nativas en formularios (`required`, `minlength`, `maxlength`, `pattern`). |
| 📊 `clase_11_tablas` | Estructura de tablas HTML (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<td>`, `<th>`). |
| 📱 `clase_12_responsive_html` | Meta etiqueta `viewport` y adaptación responsive básica. |
| 🎬 `clase_13_multimedia` | Incrustación de audio (`<audio>`) y video (`<video>`). |
| ♿ `clase_14_accesibilidad` | Introducción a atributos ARIA, contraste y buenas prácticas de accesibilidad web (A11y). |
| 🔍 `clase_15_seo` | Conceptos básicos de SEO On-Page, etiquetas `<meta>`, Open Graph y estructuración para motores de búsqueda. |

---

## 🛠️ Tecnologías utilizadas

* **HTML5** (Semántica, Formularios, Multimedia, A11y, SEO)
* **Git & GitHub** (Control de versiones)
